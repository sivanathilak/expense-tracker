# Expense Tracker

A simple responsive expense tracker built with HTML, CSS, and JavaScript.

## Features

- Add expenses
- View expenses
- Edit expenses
- Delete expenses
- Automatically calculate total expenses
- Save expenses using localStorage
- Responsive design for smaller screens

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## What I Learned

This project helped me practice:

- Working with HTML forms
- Handling user input with JavaScript
- Creating and updating DOM elements
- Using arrays and objects
- Implementing CRUD functionality
- Using localStorage to persist data
- Creating a responsive user interface

## How to Use

1. Enter an expense name.
2. Enter the amount.
3. Select a category.
4. Select a date.
5. Click **Add Expense**.
6. Use **Edit** or **Delete** to manage expenses.
